# Top-tier 回放研究 + Playbook（v1，2026-11-24）

> 目的：从 3v3 竞技场 leaderboard top 队伍的回放里提炼「可落地的机制」，对照我们 v3.3c 的差距，给出 3 条最高优先级改动、风格 A/B 参数组与验收口径。
> 数据：9 场 top 回放（官网课程×2、克利夫兰骑士×2、WR×2、从模仿到超越×2、你过来啊×1，全部帧级/manifest 在 `docs/kb/online-matches/`）；我们 15 场（近 5 场 v3.2–v3.3c + 最近 10 场 rating≥1100 基线）。
> 脚本：`/tmp/ra/top_analyze2.py`（阵型/推进/踢球/episodes/keeper/反抢/转换）、`/tmp/ra/zone_events.py`（三区触球结果）、`/tmp/ra/box_metrics.py`（禁区帧/触球/向门快球）；复跑命令见 §8。

## 0. 摘要（先看这里）

- top 队不是「控球更高」赢我们：WR 两场控球仅 44–46%（4:0 那场整场 ball 在对方禁区 **2863 帧**、我们近 5 场只有 157–728）；真正的差距在**「每次触球把球推进多远 + 前场触球的射门转化」**。
- 三区触球对比（9 场 top vs 我们 15 场，加权）：
  - 己方三区：top 每次触球球平均走 **2.29 m**、长球(≥6 m/1.5 s) **11%**、死触(<1 m) **45%**、触后 1.2 s 内出现向门快球 **20%**；我们 1.39 m / 4.2% / **60%** / 12%。
  - 对方三区：top 球平均走 **2.14 m**、短推 55%、死触 36%、**触后射门 16%**；我们 **0.75 m / 17% / 80% / 3.2%**。→ 我们到了前场也「推不动、不敢射」。
- 基线（最近 10 场 vs rating≥1100）：485 episodes → 29 shots → 5 goals；**0.5 球/场、2.9 射/场、goals/shot 0.17、shots/ep 0.06**。top 队同期 1.5–3.5 球/场。
- 三条机制改动（详见 §4）：P0 前场触球「推进≥2 m 或射门（射程 9.2 m）」；P1 己方三区解围「踢向前场边线/身后，长球占比 6–10%」；P2 禁区第二人（box touch 1→≥5/场）。预期合计 **+0.8–1.2 球/场、失球 −0.2/场**。

## 1. 方法与指标定义

| 指标 | 定义（帧级，10 Hz） | 数据来源 |
|---|---|---|
| playing_share | `commandIntents.game.state=="playing"` 帧占比 | 全部帧 |
| possession episode | 最近机器人 ≤2.0 m 的连续帧，间隔 >2 s 断开；按最近者队伍归属 | 全部帧 |
| touches / strikes | 球速跃升且最近机器人 ≤0.75 m 的帧，同机器人 0.6 s 去重 | 全部帧 |
| 球位移 travel | 触球后 1.5 s 球位移（长球 ≥6 m / 短 1–6 m / 死 <1 m） | 全部帧 |
| zone（三区） | 以进攻方向为 +x_att：己方三区 x_att<−2.33、中场、对方三区 x_att>2.33 | 全部帧 |
| box frames | ball 在对方禁区（x_att>4, \|y\|<3）的帧数；box touch=该区内我方触球次数 | 全部帧 |
| 向门快球事件 | ball 速 ≥4 m/s 且带符号 x 朝对方门运动的帧（去抖 0.6 s） | 全部帧 |
| keeper depth | 每帧「离己门最近者」当门将；深度=其到门线距离；advanced_share=深度>2 m 帧占比 | 全部帧 |
| counterpress | 丢球后 ≤8 s 内重新获得 possession 的中位时间/3 s 内比例 | frame episodes |
| 转化 | episodes→shots（球速≥3.5 且朝门、距门≤10 m、最后触球方=本队）→goals | frame + manifest goals |

限制：回放的 `kick.direction` 在机器人本体系且与球实际位移换算不闭合（median 误差 1.67 rad），**所有方向分析改用球的实际位移**；`possession` 只说明「谁离球近」，不代表控制力，需与 box/三区指标一起看。

## 2. top-3 队伍画像（帧级证据）

### 2.1 官网课程教会我踢球（rank1，2059，2 胜：3:2 / 4:2）
- **阵型/角色**：门将**不固定**——「离己门最近者」时间占比 main=58%/37%，线深中位 **2.38 / 1.47 m**、advanced_share 61%/45%，即经常有一人（不一定是 1 号）前提到中卫位扫荡；持球时 own_half_players 2.14/2.68、spread 5.8/4.3（两人分摊纵深、一人在前）。
- **推进**：踢球 5.7–5.8 次/min，p50 **5.9**、p90 6.2、hard(≥8) **0%**；travel_med 0.79–1.10 m；long_share **10–11%**（有意识的转移/门球长开）；短传占比 35–41%；dead_share 49–55%（低于我们 54–88%）。
- **终结**：shots 识别仅 2 脚/场，但进球 3–4 个 → 进球多来自**禁区混战/折射/二次进攻**（goal chain：crossing 速度 6.4–9.0 m/s，多为 20–40 帧慢球混战后突然加速）；box 帧 756–1106、box touch 4–8。
- **防守**：反抢中位 **1.23–2.27 s**、3 s 内重获 58–62%；己方三区触球后 lost 只有 8–12%（我们 15 场 9%——这一项我们不差）。
- **节奏**：playing 0.72–0.80，set play 时间花在 kickOff 25–31% / throwIn 20–26%（合计 30–40% 时间在定位球），但每次定位球首触快（无明显磨蹭）。

### 2.2 克利夫兰骑士（rank2，2020，1 胜 1 负：0:1 胜 / 2:3 负）
- **阵型/角色**：门将线深 **0.97–1.12 m**、advanced_share 0–1.3%（几乎不出击），main share 36–56%（3 台轮流最深——因为没有固定门将，谁最深谁守）；playing **0.835–0.939**（全场最多，说明定位球/死球处理最快）。
- **推进**：踢球 5.0–5.1 次/min，p50 **6.0**、p90 6.0、hard **0%**（几乎每次都用 6.0 力度，把球踢「到位」而不是踢远）；travel_med 0.53–1.02 m；long_share 1.7–6.5%；short_share 34–48%。
- **终结**：shots 7–15 脚/场、**中位射距 9.6 m**（远射多）；box 帧 834–1578、box touch 1–8。
- **防守**：反抢中位 1.28–1.39 s、3 s 内 62–69%；己方三区触球 long 27–38%（门球/解围直接踢过半场）。
- **可抄点**：①全员统一 6.0 力度、「到位率」优先；②门将贴线不出击 + 谁深谁守；③射程延伸到 9–10 m。

### 2.3 WR（rank3，2014，2:2 / 4:0）
- **阵型/角色**：门将深度 **0.18–0.54 m**（几乎站在门线上）、main share 87–98%、advanced 0（**从不出来**）。
- **推进**：p50 **9.4 / 7.02**、hard(≥8) **68% / 33%**、travel_med 1.88/0.35 m；踢球 7.9/min（2:2 场）但 4:0 场只 2.4/min → **少而重**：每次触球都用大力度把球送出去（解围/长传/射门用 9–10 力度）。
- **终结**：4:0 场 ball 在对方禁区 **2863 帧（全场一半）、box touch 10**，对手仅 81 帧 box；进球 4 个全部在对方禁区内完成（进球链 crossing 速度 3.4–8.7 m/s，均来自混战/补射）。
- **防守**：反抢中位 **0.79–1.15 s**、3 s 内 71–79%（top3 最快），丢球后立即 3 人压上逼抢，把对手压回其禁区（对手 box 81 帧 = 对手几乎没进攻）。
- **可抄点**：①丢球即反抢（1 s 内 3 人收缩到球 3 m 内）；②门将死守门线；③解围/射门一律 9–10 力度，不做无用短触。

### 2.4 泛化验证（1800+ 两套风格）
- **从模仿到超越**（rank4，2009，2 胜 0:2/4:0）：p50 5.9、travel 1.03、long 10%、keeper depth **1.98 m**（高位门将/扫荡型）、counterpress 3.17 s（慢）；box 帧中等。→ 属「控制+高位门将」变体（官网/克利夫兰同族）。
- **你过来啊**（rank6，1959，5:1 胜）：p50 4.92、travel 1.08、long 5%、keeper 1.22、counterpress 2.13；单场 5 球（对手弱）。→ 低力度但 travel 仍 >1 m，说明「力度不是唯一变量，落点/连续性才是」。
- 结论：top-3 的「每次触球推进 ≥2 m + 前场敢射 + 丢球即反抢」不是单队特例；**力度风格可 A/B（6.0 控制型 vs 9+ 硬踢型），但 travel_med ≥1.0 m 与长球 6–10% 是共同点**。

### 3.3 相同场景处理（Lead 需求 2 的场景对比）
- **ball 在己方三区时**：top 的选择顺序是 ①有空间→长踢到前场边线（long 11%）；②被压→贴边带一步再踢（short 44%）；③死触仅 45%，且 lost 12%。我们：①死触 60%（磨蹭、反复轻碰）；②长踢 4%；③触后 1.2 s 出现向门快球 12%（解围不彻底）。
- **ball 在对方三区时**：top ①直接射/传中（shot 16%）；②横向转移找空档（short 55%，travel 2.1 m）；③死触 36%。我们：①80% 死触（原地轻推）；②shot 3.2%；③short 17%。→ 我们缺的不是「到位」，是「到位后的第一脚」。

## 4. 三条最高优先级机制改动

### P0（最优先）前场触球「推进 ≥2 m 或射门」，射程 6.5→9.2 m
- **触发条件**：我方触球（最近机器人 ≤0.75 m）且 ball 在对方三区（x_att>2.33）；且当前球速 <1.0 m/s（静态/半静态球）。
- **动作选择**（伪代码，写进 `player.attack()`/前场分支或新 `push_or_shoot()`）：
```
if x_att > 2.33 and ball_speed < 1.0:
    d_goal = dist(ball, opp_goal)
    if d_goal <= 9.2 and shot_lane_clear(ball, opp_goal):
        kick(aim = far_post(goal_y ± 1.0), power = 9.0)   # 射程内果断射
    else:
        target = (ball.x + 2.2, ball.y + side_offset)      # 往球门方向至少 +2.2 m，横向避开最近防守者
        kick(aim = target, power = 7.0)
```
- **参数**：`FRONT_SHOOT_RANGE_M=9.2`（原 6.5）、`FRONT_PUSH_MIN_M=2.2`、`FRONT_PUSH_POWER=7.0`、`FRONT_SHOT_POWER=9.0`；保留 front_snap 在静止球（<0.8 m/s）优先。
- **预期**：对方三区 travel 0.75→≥2.0 m、shot_share 3.2%→≥12%、shots/场 2.9→5–6；按我们的 goals/shot 0.17–0.25，**+0.5–0.8 球/场**。
- **风险**：射门变多→球权丢失率上升（top lost 24% vs 我们 7%），可能被反击；用「射门后 2 人退防」抵消（P2 附带）。

### P1 己方三区解围：目标改「前场边线/对手身后」，长球占比 6–10%
- **触发条件**：ball 在己方三区（x_att<−2.33）且我方触球；或门将接球。
- **动作**：
```
if x_att < -2.33:
    if nearest_opponent_dist < 1.2:      # 被压
        target = opp_half_wing(y = sign(ball.y or -1)*(half_w-1.0), x = 4.0)   # 前场边线
        power = 9.0
    else:
        target = (2.0, ball.y)           # 往中场/边线送 1.5–3 m
        power = 6.0
```
- **参数**：`OWN_THIRD_LONG_POWER=9.0`、`OWN_THIRD_LONG_LONGITUDE=4.0`（进攻方向 x）、`OWN_THIRD_PUSH_POWER=6.0`；门将 clear 同目标（不再向场地中心踢）。
- **预期**：己方三区 travel 1.39→2.3 m、long 4%→8–10%、dead 60%→45%；对手在**我们禁区**的 box 帧下降 ~20%，失球 −0.2 球/场（参考 top 队把对手 box 压到 81–1100 帧）。
- **风险**：长球出界率上升（throw_in 给对方）；用「目标点在边线内 1.0 m + 力度按距离」平衡；出界后按 v3.3c 摆球纪律执行（现在 0 R-06）。

### P2 禁区第二人（box touch 1→≥5/场）
- **触发条件**：我方后场/中场持球且球在向前推进（ball x_att>-1）；非门将、非主攻的第三人。
- **站位**：`target = (ball.x + 2.5, ball.y ± 1.2)`（球门方向 2.5 m、横向距球 1.2 m，取远离最近防守者一侧），到点后随球横向平移，**保持自己在球与对方门之间、且不越位/不进小禁区**。
- **参数**：`SUPPORT_BOX_X_OFF=2.5`、`SUPPORT_BOX_Y_OFF=1.2`、`SUPPORT_BOX_MAX_X=6.2`。
- **预期**：box touch 1→≥5/场、box 帧 +30%；按 top 的「box touch→进球」约 0.3–0.4 球/触球组，**+0.3–0.5 球/场**（补射/二点球）。
- **风险**：第二人前压后后场只剩 1 人，被反击风险；要求反抢 1.5 s 内到位（用 WR 的 3 人收缩）。

## 5. 风格 A/B 参数组（3 场 A/B 选型）

| 参数 | A 控制型（官网/克利夫兰/从模仿） | B 硬踢长球型（WR） |
|---|---|---|
| KICK_POWER 基准 | 6.0（p50 目标 5.8–6.2） | 传递 6.0 / 解围射门 9.0–9.5 |
| long_share 目标 | 8–10% | 12–15% |
| travel_med 目标 | ≥1.0 m | ≥1.3 m |
| keeper 线深 | 1.2–1.8 m（高位扫荡） | 0.3–0.5 m（贴线） |
| 反抢触发 | 丢球 2 s 内最近 2 人压迫 | 丢球 1 s 内 3 人收缩到球 3 m |
| box touch 目标 | ≥5/场 | ≥7/场 |
| 适用对手 | 弱/中对手、需要控节奏 | 强对手/需要打身后、比分落后 |

- A/B 设计：各 3 场（真实对手 rating≥1000），同一 v4 代码只切参数组；验收看 §6 的 P0 指标 + goals/场，取优者作为 v4 默认。

## 7. 给我们的「抄 3 个动作」量化预期（Lead 需求 2/3）
1. **前场触球必推进/射门**（P0）：shots 2.9→5.5/场、shots/ep 0.06→0.13 → 以 0.2 goals/shot 计 **+0.5 球/场**。
2. **己方三区解围到前场边线**（P1）：对手 box 帧 −20%、失球 1.0→0.8/场（**−0.2 失球/场**）。
3. **禁区第二人**（P2）：box touch 1→5/场、box 帧 +30% → 二点球/补射 **+0.3 球/场**。
合计预期：**+0.8 球/场、−0.2 失球/场**（从 0.5:1.0 到 1.3:0.8），相当于 rating +40–60 的胜率提升幅度（top 队与我们同 rating 段的胜负差主要来自这类转化）。
