# v3.3b「摆球期纯慢爬」数值复核 + #43（713d7f30）R-06 根因

> 复核对象：T1 WIP（未提交）`_act_stopped` 摆球期纯慢爬——非门将距球 <`STOP_CRAWL_TRIGGER_M=1.6` 时以恒定 `STOP_CRAWL_SPEED=0.12` 沿球→机器人径向远离（每帧目标 = pose+径向·0.5，clamp 场内 0.4 m），其余全停；无快撤/滑行段；保留 v3.3 三区慢球强制接触 + P0-1 活球出界预判。
> 结论：**不建议按 0.12 原样提交**。数值上 `0.12×3 s = 0.36 m`（摆球期是 3.0 s，不是 2 s）在「grace 后累计」口径下会超 0.3 m；且慢爬能否同时满足 R-07 豁免与 M-02 是两个互相拉扯的约束。**真正该先修的是 #43 R-06 的代码根因（radial_escape 回退的切向弦线），慢爬只抬半径、不修根因。**

## 2. 代码根因：`_act_opp_set_play` 回退路径的切向弦线

`src/main.py::_act_opp_set_play`：`d_ball < SET_PLAY_DEF_RADIAL_PULL_DIST_M=2.4` 时
`target=_away_from_ball_point(context,ball,pose,SET_PLAY_DEF_ORBIT_RADIUS_M=3.1)` → `_field_point(...,0.3)` 夹取；若夹取后 `d_escape < max(SET_PLAY_DEF_MIN_CLEAR_M=1.7, d_ball+0.05)`，**取「距球最远的切向候选点」`ball+(−uy,ux)·3.1` 并直接 `omni_move_toward` 直线冲过去**。

本例：ball `(5.08,−4.45)`、pose `(5.485,−4.459)` → 径向原始目标 `(8.18,−4.52)` 被夹到 `(6.70,−4.20)`（x clamp 6.7、y clamp −4.2），`d_escape=1.64 < 1.7` → 切向点 `(5.154,−1.36)`。**从半径 0.48 m 处以直线冲向 3.1 m 外的切向点：弦线离球最近 = 0.48·3.1/√(0.48²+3.1²) ≈ 0.474 m**，而机器人机身+球的实际接触中心距约 0.33–0.44 m（本场实测触球时中心距 0.29 m），余量只有几厘米，执行偏差（本场实际轨迹比指令多向西偏、速度 0.14→0.49 m/s）就够碰到。

→ **修法（约 10 行）**：从半径内绝不允许「切向直线冲刺」。改为：若 `d_ball < RESTART_AVOID_RADIUS_M+0.15`，先沿 `unit(pose−ball)` 小步径向走（每帧目标 = pose + 径向·0.5，即把 v3.3b 的慢爬几何复用到 OPP_SET_PLAY 阶段、速度用正常 1.2 m/s）；`d_ball ≥ 1.6` 后再走轨道点。这样被动触球概率为 0（距离单调增），且开踢瞬间径向速度远大于 R-07 豁免线。

## 3. M-02 数值复核（Lead 问①，T1 问①）

关键：**摆球期是 3.0 s（`ball_placement_started.expectedSeconds=3.0`，#43 实测 425.212→428.226=3.014 s），不是 2 s**。慢爬若从 detected stopped 开始，可持续 2.5–3.0 s：

- 0.12 m/s → **0.30–0.36 m**；0.10 → 0.25–0.30 m；0.08 → 0.20–0.24 m。
- 若裁判口径是「2 s 滑动窗、窗内含 grace 前运动」：0.12×2=0.24 m 安全；但见下。
- 历史证据都显示裁判上报的 `distanceMoved` 在 **0.301–0.339 m / durationSinceStopped 1.8–2.37 s** 触发：
  - v2.7 #3 60d19472：0.332 m / 2.9 s（慢爬 0.12 跨 grace）；
  - v2.14 #10 0116ec1d：0.3348 m / 2372 ms（**crawl 0.12×2.37 s≈0.285 m + 残余速度**，见 `src/param.py` 现行注释）；
  - v3.1 #36：4 张 0.305–0.317 m / 1.8–2.05 s；v3.1b #37 0.3055/1.98 s、#38 0.304–0.326、#39 0.304–0.339（都是 vacate 0.8–1.2 m/s 后残余）；
  - v2.13（窗口 0.5 s，移动在 grace 内完成）→ 0；v3.2/v3.3 #40–#44（全停）→ 0。
- **解释**：若真是「2 s 滑动窗且纯路径」，0.12×2=0.24 永远不该罚；但 v2.7/v2.14 的 0.33 出现在 duration 2.37–2.9 s，且 v2.14 的 0.3348 已被复盘拆成「crawl 0.285 + 残余 0.05」。这说明裁判判定更接近「**grace(1.5 s) 结束后的累计位移**」或「当前窗包含 grace 前后混合运动」，**不能用 2 s 滑动窗自证安全**。
- 还有两个容易被忽略的叠加项：①我方在哨前一帧常还带 P0-1/line_clear 的前进速度（#43 哨前 robot1 实测约 0.5 m/s），滑行残速会与慢爬落入同一判定窗；②`_act_stopped` 的 `stopped_since = now − STOP_STATE_LATENCY_COMP_S(1.15)` 使 `elapsed` 首帧就 >1.15，意味着慢爬从检测那一刻起立刻开始，检测越早、爬得越久。
- **建议**：若坚持慢爬，用 **0.08 m/s**（3 s 累计 0.24 m，留 0.06 m 余量给残速/噪声），不要用 0.12；或者保留全停（v3.2/v3.3 连续 5 场 0 M-02 已被证明）。

## 4. R-07 豁免分析（Lead 问②，T1 问②）

- 豁免条件：主罚第一次触球瞬间，距球 ≥1.45 m，或 **500 ms 内径向远离球速 ≥0.05 m/s**。
- 0.12 m/s 理论满足（0.06 m/500 ms，>0.025 m），0.08 理论也满足（0.04 m/500 ms）但**贴着 `POSITION_TOLERANCE=0.05` 的测量噪声**：500 ms 内位移 0.04 m 与 0.05 m 的容许误差同量级，实测速度可能被判成 0。**要可靠拿到豁免，径向速度需要 ≥0.12 m/s（0.06 m/500 ms）**。
- 这与 M-02 的 0.08 上限**互相拉扯**：慢爬速度取 0.12 时 R-07 稳、M-02 险；取 0.08 时 M-02 稳、R-07 的 500 ms 测速可能不达标。**纯慢爬无法同时稳妥满足两约束**——这正是 v2.13→v2.15→v3.1b 反复在该处吃罚单的数学原因。
- 「不触球 → R-06 不触发」成立：R-06 需要防守方在主罚触球前触球。但注意：**球被主罚踢出后打在我们身上不算 R-06**（那是正常触球，但可能让 indirect 进球合法化，属另一类风险）。所以 0.36 m 的净位移（0.48→0.84 m）不是「物理安全距离」，只是「不会自己撞球」的距离。
- 还有一条：如果慢爬在摆球期内被 clamp/逻辑打断而**停下**，那么开踢瞬间径向速度=0，距球仍 <1.45 m → **R-07 成立**；#43 若把慢爬停在 0.20 m 处，就正好会踩这个坑。

## 6. 替代最小方案（按推荐顺序）

- **A（推荐，先于慢爬）：全停 + 修 radial_escape 弦线 + 界外球禁入**。
  1. `_act_opp_set_play` 回退分支：`d_ball < RADIAL_PULL` 时先径向小步撤到 1.6 m，再走轨道；禁止切向直线。（10 行）
  2. 界外/待摆期非门将不进 1.6 m 圈；`attack:line_clear` 不追界外球。（8 行）
  3. 慢爬暂缓。验收：#43 型场景（我方最后触球出界 + 我方有机器人在摆球点 2 m 内）复演 0 触球；连续 2 场 M-02=0、R-06=0、R-07=0。
- **B（若 Lead/T1 坚持慢爬）**：全停的 A 两条照做 + 慢爬速度 **0.08 m/s**、只对 `d_ball < 1.6` 的非门将、爬行期间不得因 clamp 停下；并用回放量测「500 ms 径向位移 ≥0.05 m」与「裁判 window 内累计 ≤0.28 m」两项，任一不达标回退 A。
- **C（最小单点）**：只修 radial_escape 弦线。理由：#43 的触球动作是它，全停本身在 5 场里 0 M-02；弦线修好后，从 0.48 m 半径出发会先径向走到 1.6 m，同样 1.2 m/s 移动，R-07 豁免也满足。

## 7. 验收口径（建议 T1 在门禁/复盘里固化为数字）

- 复演/回放：①「我方最后触球出界后 1 s 内，我方非门将在摆球点 2 m 内」帧数 = 0；②「摆球期 + 开踢前后 1 s，我方任一机器人距摆球点 <0.35 m」帧数 = 0；③「开踢瞬间距球 <1.45 m 且 500 ms 径向速度 <0.05 m/s」帧数 = 0。
- 线上 2 场：M-02=0、R-06=0、R-07=0、retake ≤1/场；且「我方 last-touch 出界后 3 s 内我方在球 1.45 m 内」帧数相比 v3.2 下降 ≥80%。

## 8. 给 T1 的结论（同日已发送）

1. 0.12 m/s **不要原样提交**：3 s 摆球期累计 0.30–0.36 m，且 v2.7/v2.14 的「crawl 0.12 跨 grace → 0.33 m」已有先例；若必须用慢爬改 0.08。
2. R-07：0.08/0.12 分别在「M-02 安全/豁免可靠」两端，不能同时稳妥；先修 chord 后靠开踢后的正常 1.2 m/s 径向移动拿豁免更稳。
3. #43 的 R-06 不是全停冻结所致，是 radial_escape 切向弦线；先修它（C 方案，10 行），慢爬可留到下一轮。
