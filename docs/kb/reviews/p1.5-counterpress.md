# P1.5 反抢/退防配方（丢球后 3 秒）

> 目的：回答「丢球后 3 s 内做什么」——top 与我们的对比 + 下一版（P1.5）可落地配方。
> 数据脚本：`/tmp/ra/loss3s.py <uuid> <focus>`（输出每场双方「丢球→3 s」的触球序列/球速/球位移/3 m·5 m 内人数/接近速度/重获时间/3 s 末落区/对方触球数 + 进球后重启 3 s 行为）。结果在 `/tmp/ra/loss/*.json`、汇总 `/tmp/ra/loss/agg.json`。

## 1. 方法
- 触球检测：球位帧间差分 + 最近机器人 ≤0.75 m（同机器人 0.6 s 去重）。
- 「丢球事件」= 连续两次触球方改变（A→B，间隔 ≤3 s），A 为丢球方。
- 对每个丢球事件统计：+1 s/+2 s/+3 s 时 A 方 3 m 内人数、5 m 内人数与平均接近速度；3 s 内 A 是否重新触球（夺回）及时间；3 s 末球位置（按 A 进攻方向的 own/mid/opp 三区）；3 s 内对方触球次数、球总移动距离。
- 另统计进球后 3 s（READY 结束、重新 playing 起）：我方在对方半场人数、近球人数、球移动。

**读法**：
1. 我们**人数并不少**（+1 s 3 m 内 1.5–2.3 人，接近 top），问题在**抢而不下**：`11f01b49` 8 次己方半场丢球里对方 3 s 内还能触球 1.91 次（全样本最高），夺回率仅 38%；`08ac7eb6` 虽然夺回 89% 但对方触球 1.56 次——我们把球"碰"出来又被对手拿回。
2. top 的共同点：**第一个人扑球的同时第二个人封内线**（WR 2.62 人 / 官网 1.62 人），夺回后立刻硬踢出危险区（3 s 球移动 2.8–4.2 m），对方触球 ≤1.3 次。
3. 进球后 3 s：双方都遵守开球站位（0–2 人在对方半场），**无区分度**；差距不在重启期，在开放回合的丢球后 2 s。
4. 我们丢球后最危险的模式（结合各场失球复盘）：己方三区/中场丢球 → 最近者慢 0.5–2 s 才启动 → 对手直线推进 1.8–6 m/s 一脚射门。典型：v3.2 `08ac7eb6` C1/C2（丢球后 3.4/4.6 s 被射）、`11f01b49` 174.8。

## 3. P1.5 配方（可直接映射实现）

**触发**：本队触球方 A 的球权丢失（对方触球 B，球距 A 最近球员 ≤2.5 m 且 A 已不在球 0.75 m 内）。

**规则**（所有非门将参与，按角色分）：
1. **第一扑（0.15 s 内决策）**：最近非门将 → 直接 `omni_move_toward(ball, speed=1.8 m/s)`，不做绕后/不做 kick 任务（避免 kick 任务慢速接近），直到球离开己方三区或失去球权 2 s。
2. **第二封（0.3 s 内）**：次近非门将 → 目标 = `ball + 0.55·unit(ball→our_goal)` 的反向延长线偏球门侧 0.6 m（封住对手向前的直线），速度 1.6 m/s；不追球、不抢断。
3. **第三人（最深者）**：站 `ball→own_goal` 连线上距球 `B_GOALSIDE_GAP_M=2.5 m` 的点，y 方向夹到 ±2.8 m；**禁止两人同时扑球**（若第一扑者失位，第二人接替，第三人补线）。
4. **门将**：只在门线附近（0.2–0.5 m），y 跟球 0.85×ball.y 并夹 ±1.15 m；**不因丢球出击**（除非球已进禁区且距门 <4 m）。
5. **夺回后 1 秒**：第一脚必须是朝边路/对方半场 ≥4 m 的硬踢（power 9.4），禁止在己方三区内短传或带球；没有向前线路时踢向边线外（对方界外球）也比被二次进攻好。
6. **丢球在对方三区**：立即 2 人反抢（第一人 1.8 m/s 扑球，第二人封回中路），最远者回中线；反抢 2 s 未果则整体回落，不再在对方半场丢位置。

**参数（建议名）**：
```python
PRESS_TRIGGER_DIST_M = 2.5
PRESS_FIRST_SPEED_MPS = 1.8
PRESS_SECOND_SPEED_MPS = 1.6
PRESS_BLOCK_OFFSET_M = 0.6
PRESS_MAX_DURATION_S = 2.0
PRESS_GOALSIDE_GAP_M = 2.5
PRESS_GOALSIDE_Y_LIMIT = 2.8
PRESS_CLEAR_AFTER_REGAIN_POWER = 9.4
PRESS_CLEAR_MIN_DIST_M = 4.0
KEEPER_DEPTH_M = 0.35
KEEPER_Y_GAIN = 0.85
KEEPER_Y_LIMIT = 1.15
```

**预期收益**：己方半场丢球后的「对方 3 s 触球」1.9→≤1.2、夺回率 38–50%→60%+、夺回中位 ≤0.9 s；按近 10 场 0.5 球/场、丢球后 3–5 s 内被射正约 1/3 的失球来源，预计失球 −0.3～−0.5/场。

**验收**（每场跑 loss3s.py，3 场均值）：
- 己方半场丢球：夺回率 ≥60%、夺回中位 ≤0.9 s、对方 3 s 触球 ≤1.2 次、球 3 s 移动 ≥3.0 m；
- 全局：丢球后 5 s 内被射门 ≤0.3 次/场（需在复盘脚本中按「丢球事件 + 后续 shot 检测」新增）；0 R-06/R-07/M-02；不得增加 `inactiveRobot`。
- A/B：与 v4.0a 同 3 场对比，P1.5 组失球 ≤A 组 −0.3/场 且 box 帧不下降 >15%。

## 4. 与风格 A/B 的关系
- 控制型（A 组）配 P1.5 的「2 人围抢 + 1 人封线」；硬踢型（B 组）配 P1.5 的「反抢后第一脚硬踢出边」。
- 若实现成本受限，P1.5 最小版 = 规则 1+2+5（第一扑 + 第二封 + 夺回即硬踢），半天可落、收益/风险比最高。
