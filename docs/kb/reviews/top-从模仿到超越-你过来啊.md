# Top 队复盘（泛化验证）：从模仿到超越（rank4/2009）与 你过来啊（rank6/1959）

## 从模仿到超越（rank4，2009，52 局 73.1% 胜）
- 样本：`c884e855`（away 2:0 胜 Robonaldo）、`b1e269e2`（away 4:0 胜 海底小纵队）。
- 风格 = **控制型 + 高位门将扫荡**：p50 5.9、travel 0.88–1.19 m、long 8–12%、playing 0.82–0.87。
- 门将线深 **1.74–2.23 m**（全样本最高之一），advanced 高；反抢中位 2.8–3.5 s（偏慢）。
- 结论：与官网/克利夫兰同族（控制+高位防守），但反抢更慢 → 证明「反抢快」不是控制系的必要条件；其赢球靠**推进到位率**（travel 1.0+、long 10%）。

## 你过来啊（rank6，1959，56.0% 胜）
- 样本：`78f4b192`（away 5:1 胜 ABC_4990，对手偏弱）。
- 风格 = **低力度高连续性**：p50 4.92（低于我们部分场次）、travel 1.08 m、long 4.9%、playing 仅 0.626（死球多）。
- 打出 5 球：shots 8、box touch 数据为 0（该场对方较弱，box 数据受对手影响）；counterpress 2.13 s。
- 结论：**力度不是唯一变量**——p50 4.9 也能把球稳定推进 1.08 m/触球（我们 0.53–1.16 但 dead 54–88%）；关键仍是「触球落点 + 连续性」。

## 对 playbook 的泛化结论
1. 控制型（官网/克利夫兰/从模仿）：p50 5.9–6.0、long 6–12%、keeper 线深 1.0–2.2 m、反抢 1.2–3.5 s 均可赢 → **参数组 A 区间宽，可 A/B 选 6.0 + 高位门将**。
2. 硬踢型（WR）：p50 8–9.4、hard ≥33%、keeper 贴线 0.2–0.5 m、反抢 ≤1.2 s → **参数组 B**。
3. 共同点（必须抄）：travel_med ≥1.0 m、长球 6–10%、dead ≤50%、box 在场（数量随风格变）。
