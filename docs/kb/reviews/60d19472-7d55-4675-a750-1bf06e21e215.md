## 7. 一句话结论

**本场最大失分点（更正后）：v2.7 的 presser 分支 `NameError: name 'ball'` 让全队冻结 1031 帧 / 108.9 s，6 个失球全部发生在「冻结中 / 刚解冻」的静止慢球上；「进攻瘫痪、门前围观」是冻结假象，不是对齐门控，也不是战术选择。最大亮点：agent 逻辑本身没崩（25 次摆球、kick 尝试 105 次仍在下发），且这次冻结在离线复现中被完整定位——教训是必须用 `tools/replay_playcheck.py` 把「play() 整场 0 异常」做成提交门禁。**
