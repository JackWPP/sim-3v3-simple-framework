# 了解仿真足球赛

欢迎来到仿真足球赛。这是整套教程的第一课，我们先来了解3V3 仿真足球赛比什么、策略 **Agent** 是什么、以及怎样在自己的电脑上开始比赛。先建立直观感觉，再学原理，我们轻松上路。

🎯 **学习目标**

- 了解 **3V3仿真足球赛**
- 理解策略Agent
- 在 **Booster Studio** 里开启比赛。

## 单元1：了解 3V3 仿真足球赛

仿真足球赛球场长 14 米、宽 9 米，两侧各一个球门。场上没有人类运动员，两支球队各由 3 个机器人组成。规则和人类足球相似，把球踢进对方球门就得分，得分多的一方获胜；有开球、有任意球、有角球、也有犯规判罚。

![这张图片呈现了3V3仿真足球赛的完整场地场景，场地为长14米、宽9米的标准仿真足球赛场，两侧分别设有球门，边线与球门边的围挡上印有“BOOSTER”字样。场地内共有6个机器人队员，分为红、蓝两队各3人，场地中央放置着足球，红队队员处于己方半场靠近球门的区域，蓝队队员分布在中场及对方半场，整体还原了仿真足球赛的赛场布局，直观展现了3V3仿真足球赛的比赛场景样貌，与文档中介绍的3V3仿真足球赛内容相呼应，清晰呈现了该赛事的场地及队员配置情况。](https://feishu.cn/file/MO7nbmPksovL6DxP5wFc5ZkSnoc)

和普通的足球比赛不同，场上的机器人运动员不会自己思考。它们接收指令并行动，不会主动判断进攻或防守的时机。

你在比赛中的角色是主教练，不必进入球场，而是要开发策略Agent，告诉场上的三个机器人该往哪跑、要不要拼抢、往哪个方向射门。 **3V3 仿真足球赛比的，是会踢球的策略Agent。你要将对足球的理解，写成策略Agent。平台负责把策略Agent接入比赛，让它在比赛开始后接管决策。你的策略越聪明，球队就踢得越好。**

仿真足球赛瞬息万变，一秒之内可能数次切换攻守态势。你的策略需要在 1/30 秒内做出反应，不停运转，周而复始：看一眼球场 → 想一下策略 → 发一条指令 → 再看下一眼。

> 机器人足球世界杯 RoboCup 自 1997 年起举办，有一个雄心勃勃的目标——"到 2050 年，一支全自主的人形机器人足球队，能按国际足联规则战胜人类世界冠军队"。几十年来，这个目标催生了大量机器人学、人工智能、多智能体协作的研究。
> 
> 3V3 仿真赛是其中入门门槛低、最适合入门的组别之一。你不需要懂机械、不需要调电机，只要会写策略逻辑，就能让一支球队跑起来。本教程中提到的3V3仿真赛基于 Booster 加速进化平台的机型与仿真环境，遵循 RoboCup 风格的规则。示例策略稍作改动，未来就可以对接真实机器人，走上真机赛赛场。

## 单元2：什么是 Agent？

在真实足球里，教练在场边大喊战术、球员在场上执行；在仿真足球里，没有真人教练实时指挥，取而代之的是 Agent。Agent 就像球队的"数字大脑"，是一段住在电脑里的程序，在每一瞬间决定三个机器人分别去哪、做什么。

<callout emoji="💡">
Agent 是被 Booster Studio 加载、构建、部署到虚拟或真实机器人上的持续决策程序。在比赛中不断"看球场 → 想策略 → 发指令"。
</callout>

<readonly-block type="isv"></readonly-block>

Agent 不是某个具体的机器人，而是这支队伍的集体意志。你可以把 Agent 想成一款足球游戏里的"战术面板"。Agent 在比赛中只需要不断重复回答一个问题："**此刻，我的三个球员该干什么？**"

假设对方刚刚把球踢出界外，裁判机判罚我方边线球。你的 Agent 必须立刻理解当前的比赛阶段，派出离球最近的球员去发球、另两人跑位接应，而不是傻乎乎地继续全场追球。从识别局面到切换打法，就是 Agent 每帧都在替你做的事。你后续要写的，就是一套"看局面、定打法"的策略。

## 要点总结

- 3V3 仿真赛用代码踢足球，选手写策略Agent程序指挥三个机器人参赛；
- Agent 是球队的数字大脑，高频决策机器人去哪、做什么；
- 借助 Booster Studio，不写代码、没有实体机器人也能一键跑通本地仿真比赛；
- 策略框架上手快、上限高，选手可 Vibe Coding 速改策略。
