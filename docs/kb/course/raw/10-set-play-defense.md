# 专题优化-定位球防守

定位球是进攻的好机会，应该好好把握。同时，定位球也是对手得分的好机会，本模块从防守哲学讲起，帮你设计出更好的定位球防守策略。

🎯 **学习目标**

- 看懂 `OPP_KICKOFF` 的保守打法
- 写出以封堵为主的防守分支
- 实现人墙防守策略

---

## 单元1：防守也是一门艺术

很多新手认为防守就是从对方脚下抢球，写出的策略是谁离球近谁去抢。可在比赛中的顶级防守里，抢断只占很小一部分，大部分时间防守球员在调整站位，他们没有碰到球，却让对手无路可走。

防守的核心哲学可以概括为一句话：用空间换时间、用结构换机会。"用空间换时间"，是指你不必第一时间把球抢下来，只要延缓对手的推进速度，己方的阵型就有时间重新集结；所谓"用结构换机会"，是指全队站位形成的那张"网"本身就是武器，对手在网里越久，出现失误的概率就越高，而失误的那一刻就是你反击的机会。理解了这两句话，你就明白为什么在防守时，`walk_to` 有时比 `attack` 更重要。

把这套哲学拆开，有五条贯穿百年足球发展的原则。你可以尝试将它们映射到你的代码：

1. 压缩空间——球员之间保持很小的纵向、横向距离，让对手无处可钻。现代足球里无论是高位逼抢还是低位死守，都讲究紧凑站位。三个人站成一个边长 3 米的三角形，和站成一条散开 8 米的直线，覆盖能力天差地别。在代码里，参数 `SUPPORT_DIST_M`（`param.py`，默认 3.0）决定支援球员站在球与己方门连线上多远的位置，值越小阵型越紧凑，越不容易被中路直塞打穿，代价是反击时距离对方球门更远。
2. 区域联防——每人守一块区域，而不是死盯一个人。好处是阵型不易被拉散，无论对手怎样跑动，我方总有人控制关键空间。缺点是区域交界处可能出现空档。这条原则对应的是<cite doc-id="PRTgwO9S9iFBYEkmroic1Yp1nJh" file-type="wiki" title="专题优化-分区策略" type="doc"></cite>。你可以把场地划成若干区块，每个球员对自己那块负责，球进入哪一区就由该区的人上前。
3. 人墙——在任意球的射门路线上排人，缩小门将需要扑救的角度。本质是阻挡最危险的球路。
4. 包夹——两人对持球者前后夹击，一人堵传球路线、一人逼抢，迫使他仓促出球。在代码里，这对应对持球对手进行盯人干扰。你可以尝试读 `context.opponents` 找出离球最近的对手，派球员贴身干扰。
5. 由守转攻——抢断成功的那一瞬，是全场最好的反击窗口，因为对手刚刚还在压上进攻，阵型是散的。好的防守不仅为了不丢球，同时会考虑如何更好地进攻。在代码里，这意味着一旦球权到手，就要立刻安排球员前插跑位，而不是慢悠悠地重新集结。

<callout emoji="💡">
进攻代码关心的是怎么移动球，防守代码关心的是"站在哪里，让对手最难受"。
</callout>

## 单元2：球门球和中场球的防守战术

我们来讨论两个距离我们球门较远的定位球防守：**对方中场开球**（`OPP_KICKOFF`）和**对方球门球**（`GOAL_KICK`）。

`_act_opp_kickoff`（`main.py`）目前很保守：

```Python
# src/main.py（节选）
guard = min(players, key=...离己方门最近...)   # 一人守门
guard.guard()

rest = [p for p in players if p is not guard]
r = context.field.circle_radius                 # 中圈半径 1.5m
slots = [(-r - 0.5, 0.0), (-r - 2.0, 0.5)]     # 其余两人退到中圈外固定点
for p, target in zip(rest, slots):
    p.walk_to(target, avoid_ball=True, avoid_robots=True)
```

这里的策略是"合规优先"的退守。先选离己方球门最近的人去守门，因为他跑回门线成本最低。中间用 `context.field.circle_radius` 读出中圈半径，再往外推 0.5 米和 2.0 米算出两个退守点（规则要求对方开球时我方必须退到中圈外）。最后 `walk_to` 一律带上 `avoid_ball=True`，这是防守代码的铁律：宁可绕路，也绝不碰球。因为在对方开球时触球会因违规被罚下。

目前策略点位写死，缺点明显。不管球往哪边发展，两个人都站在同样的位置，缺少变化，容易被针对。

对方在距离球门较远处发球，我方球门暂时安全。此时全队最该做的三件事是：

1. **堵住最短的那条线**。对手想进球，球最终必须经过"球 → 我方球门"这条连线。把人放在这条线上，就是最高效的封堵。 `support()` 会把球员放在球与己方门中心连线上、距球 `SUPPORT_DIST_M` 处。
2. **分层，不要挤在一起**。三个人站成前中后三层（第一落点、第二落点、门线），比三个人挤在同一距离上有用得多。对手突破了第一层，还有第二层。
3. **只占位，不触球**。在 `OPP_KICKOFF` / `OPP_SET_PLAY` 阶段，触球即违规。所有走位都要带 `avoid_ball=True`，让避障系统把球当成障碍物绕开。

如果对方选择开球直接大脚攻门，我们也应做针对性防守。我们可以考虑三人在球的路线上创造最大的阻挡面积。如果对手喜欢吊门，我们还要考虑球的落点。因为远射的球必然沿着"球 → 我方球门"这条线飞，所以封堵者不是随便站在门前，而是站在这条射门线上。多人封堵时，建议加上水平偏置。这样多人加起来覆盖的横向宽度更大，足以挡住相当一部分射门角度。我们通常应该安排一名门将留在门线做最后一道保险，避免身后完全空门。

## 单元3：定位球防守战术

状态机分支函数 `_act_opp_set_play`（`main.py`）负责定位球防守，现在直接调 `_act_normal`：

```Python
# src/main.py
def _act_opp_set_play(context, players, store):
    _act_normal(context, players, store)   # TODO: 实现自己的逻辑
```

这行代码，是一个大坑。`_act_normal` 的第一件事就是挑一个 `attacker` 去 `attack()`。在对方定位球阶段，`attacker` 追球后踢球等于主动送上门去被罚下。你要做的第一件事，就是把这一行换成符合规则要求的防守逻辑。

`get_set_play_type(context)` 能告诉你对方是什么定位球，你可以按类型设计防守：

| 对方定位球 | 建议防守 |
|-|-|
| `CORNER_KICK`（角球） | 禁区内密集站位，门将出击或守点；派一人守近门柱、一人守小禁区线 |
| `THROW_IN`（界外球） | 就近压迫持球人 + 区域回收 |
| `GOAL_KICK`（**对方球门球**） | 见下方"对方球门球策略" |

定位球防守策略的编写位置和进攻策略类似，可参考<cite doc-id="GYriwP4YMiKeIrkyzCzc20pOnK3" file-type="wiki" title="专题优化-定位球进攻" type="doc"></cite>。

## 单元4：实现"两人排人墙、一人守门"的防守策略

对方在我方半场获得直接任意球时，最经典的防守配置就是"**两人排人墙、一人守门**"。

<grid>
<column width-ratio="0.500000">
### 优势：
1. **简化门将扑救任务。** 没有人墙时，门将要防守整个球门宽度；有了人墙挡住近角一侧，门将只需要守住另一侧。人墙把一道选择题从"左边还是右边"变成"只能是右边"。
2. **逼迫对手选择更难的进攻方式。** 人墙立在那儿，对手要么越过它（吊射，精度难控制），要么改为传球（那就从"射门威胁"降级成"运动战"）。每一种替代方案都比直接抽射更难。
3. **占位不触球，零违规风险。** 人墙全程只是站在那里，不去碰球，完美符合定位球阶段的规则约束。
</column>
<column width-ratio="0.500000">
### 代价：
1. **可能被绕过。** 如果人墙只覆盖射门线的正中间，对手可以选择往空档踢，机器人不得不花时间转身，防守难度高。
2. **可能被吊射。** 机器人不会跳，人墙的"高度"是固定的。吊射就是人墙的天然克星。
3. **两个人被"锁死"了。** 两名人墙球员在整个定位球期间几乎不做别的事，等于我方在这段时间只剩门将一个机动兵力。如果对手选择短传而不是射门，你的人墙就白排了——这也是为什么职业球队会根据距离决定"排几个人"：距离远就少排甚至不排。
</column>
</grid>

理清了优劣，如果你决定这样防守，可以按下面四步构建策略：

**第一步：计算射门路线。** 对手射门时，球必然沿着"球 → 我方球门中心"这条线移动。用 `angle_to(ball.x, ball.y, *own_goal(context))` 得到这条线的方向角。这条线是整套战术的坐标轴，人墙的位置全部相对它来定义。

**第二步：分配离己方球门最近的人为门将。**因为定位球可能发生在任何时候，球员位置随机；让最近的人回去守门，到位最快。`min(players, key=离己方门的距离)` 一行搞定。

**第三步：人墙沿射门线站到球前方 2.0 米处，并横向错开。** 先沿射门线方向前进 `OPP_SET_WALL_DIST_M`，得到"墙的中心点"；再让两名球员分别往两侧各偏 0.3 米，形成一堵有宽度的墙。

**第四步：所有走位避免触球。** 人墙球员离球近，容易误触球。策略应把球看作障碍物，让路径规划绕开它，避免误触球被罚下。

参考策略代码：

```Python
# 伪代码，填入 _act_opp_set_play 的 DIRECT_FREE_KICK 分支
def _act_opp_free_kick(context, players, store):
    ball = context.ball
    if ball is None:
        for p in players: p.stop()
        return

    # 第一步：射门线 = 球 → 我方球门中心
    gx, gy = own_goal(context)
    shot_dir = angle_to(ball.x, ball.y, gx, gy)

    # 第二步：门将 = 离己方门最近者
    keeper = min(players, key=lambda p: dist(p.pose.x, p.pose.y, gx, gy))
    keeper.guard()

    # 第三步：其余两人在射门线上、距球 OPP_SET_WALL_DIST_M(2.0m) 处排人墙
    wall_players = [p for p in players if p is not keeper]
    for i, p in enumerate(wall_players):
        wx = ball.x + math.cos(shot_dir) * OPP_SET_WALL_DIST_M
        wy = ball.y + math.sin(shot_dir) * OPP_SET_WALL_DIST_M + (i - 0.5) * 0.6
        p.action = "wall"
        # 第四步：只占位，绝不触球
        p.walk_to((wx, wy), avoid_ball=True, avoid_robots=True)
```

射门线用 `angle_to` 求出后，`math.cos/sin` 把它还原成单位方向向量，再乘以距离就得到"沿这条线走 2 米"的坐标。门将选择用 `min` 配合距离函数，选出的人执行 `guard()` 即可。

`OPP_SET_WALL_DIST_M`（`param.py`，默认 2.0m）可直接调。人墙太近可能违规、太远又失去意义；2.0m 是个经验起点，用你自己的比赛数据去校准它。

## 章节练习

前面写的是给定防守坐标的区域防守。你可以尝试设计盯人防守策略。当对方发球时，指定一名球员专门去贴防对手的接应球员，其余人回防。

目标：在 `OPP_SET_PLAY` 或对方控球的局面下，实现"1 人盯人 + 1 人回收 + 1 人守门"。

实现思路：

1. 找出盯防对象：从 `context.opponents.values()` ，用 `min` 排除离球最近的发球队员，选择另一个等待接球的接应队员；
2. 选出盯防者：在我方球员里，选离这个接应队员最近的去盯他。
3. 算盯防站位：不要移动到接应队员的坐标，会撞上，倒的可能是自己。而要站在接应队员和球的连线上、距接应队员较近的位置。避免让接应队员轻易拿到球，才叫盯防。
4. 其余两人：一人 `guard()` 守门，一人用 `support()` 或走到中路做区域防守，补上盯防者离开后留下的空当。
5. 合规：所有走位一律 `avoid_ball=True`。盯人时球员往往离球很近，这是最容易误触球的场景，务必反复确认。
